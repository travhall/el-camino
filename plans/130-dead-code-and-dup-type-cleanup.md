## Why this matters

Four unrelated, independently-verified pieces of unnecessary code live in this
repo: a duplicate type definition, a dead function, a dead enum member, and an
unused dependency. None affect behavior; all add small amounts of noise a
future reader has to mentally filter out. Bundled into one plan because each

`plans/041-quick-wins-cleanup.md`.

In `src/lib/site-config.ts`:
1. Delete the `SocialLink` interface (lines 2-6).
2. Add `import type { SocialLink } from "@/lib/socialLinks";` near the top of
   the file.

   `social: [...]` array literal) unchanged — the import satisfies the same
   type reference.

**Verify**: `grep -n "SocialLink" src/lib/site-config.ts` → shows the new

after it) untouched.
